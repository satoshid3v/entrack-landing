# Entrack Landing Page (Cloudflare Pages)
Desarrollado por: **Vertice Codeium**

Sitio web público y funnel de conversión de alta velocidad para **Entrack**, optimizado para despliegue en **Cloudflare Pages**.

## 🚀 Despliegue en Cloudflare Pages
1. **Build Command:** `npm run build`
2. **Build Output Directory:** `dist`
3. **Node Version:** 18+ o 20+
4. **Variables de Entorno (Opcional):**
   - `VITE_APP_URL`: URL del software funcional `EntrackSystem` (por defecto: `https://app.entrack.co`).

## 💻 Desarrollo Local
```bash
npm install
npm run dev
```

## 📦 Producción
```bash
npm run build
```
Genera la carpeta `dist/` estática, autocontenida y lista para CDN global.
